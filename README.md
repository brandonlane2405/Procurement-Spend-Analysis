# Procurement-Spend-Analysis
### Overview
This project analyses procurement spending data using Power BI to identify spending patterns, supplier concentration and category-level expenditure trends. The dashboard was developed to provide procurement & operations teams with visibility into spending metrics to support data-driven decision-making. 

### Business Problem
Procurement teams often manage large volumes of invoice & supplier data, which makes it difficult to identify cost drivers & spending trends. The analysis' objective was to:
- Monitor procurement expenditure
- Identify high-spend suppliers
- Compare spending trends between months across years
- Suggest cost optimisation recommendations

### Skills Used
- Data Modelling (Had to adjust relationship cardinality for filters to work)
- KPI Reporting
- Power query to clean data (wrong data type adjusted)
