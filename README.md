# Procurement-Spend-Analysis
### Overview
This project analyses procurement spending data using Power BI to identify spending patterns, supplier concentration and category-level expenditure trends.
The dashboard was developed to provide procurement & operations teams with visibility into spending metrics to support data-driven decision-making.
